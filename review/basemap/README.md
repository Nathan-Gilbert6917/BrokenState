# The base map: screenshots

Taken in headless Chromium from prepared saves (2026-10-19), 1500 × 900. Every base has a square grid map of its own
(`prototype/src/sim/basemap.js`, the base window's Base map tab); it is the map a horde or a raid fights over.

## Base management, by base type

| Shot | What it shows |
| --- | --- |
| `01-hub-base-map-tab.png` | The main hub's Base map tab: the grid (168 to 300), the yard, what is placed by hand and by the game, the rules. |
| `02-hub-map.png` | The hub's map opened: the main house, cellar and well in the middle, the placed buildings, fields, barricades, the pits and the trench outside the wall ring, two buildings going up as outlines. |
| `09-outpost-base-map-tab.png`, `10-outpost-map.png` | An outpost (72 × 72 grid): the shack, spring and pantry in the middle, a bunkhouse, a storehouse, a watchtower, barricades and spike pits. |
| `12-shelter-base-map-tab.png`, `13-shelter-map.png` | A shelter (48 × 48): the bunk shack behind its barricade and fire, crates, a rain catcher, the crop plots and the truck. |
| `15-camp-base-map-tab.png`, `16-camp-map.png` | A camp (40 × 40, the camp within 20 × 20): tents round the fire, the cache, a rain catcher and a barricade. |
