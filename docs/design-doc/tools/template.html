Broken State

A top-down zombie survival strategy game set in the State of Calder. Lead a hub of survivors, manage them like a colony, deal with rival groups like a 4X, and send teams out on raids where every survivor and every bullet counts.

This draft describes the game as it is built in the prototype today. Every sprite shown here is rendered from the game's own drawing code.
